# eml-sr_biodata プロジェクト概要

本プロジェクトでは、EML（Exp-Minus-Log）を用いたシンボリック回帰（eml-sr）などのモデリング手法を生物学的データに応用した研究実績についてまとめ、こちらでも実験的に試してみることを目的としています。

現在は、以下の研究・リポジトリを中心に解析を進めています：

1. **EMLベースの記号回帰と粗視化モデリング (MEb)**
   * `MEb/` (旧名: Manuscript_EML_biophysics): 非単調な応答を表現するEML演算子を用いた記号回帰やネットワークの粗視化に関する研究。

2. **哺乳類のエピジェネティック・クロック（加齢時計）研究**
   * `age_cat/`: ネコの加齢クロックおよび哺乳類全体の保存されたDNAメチル化アレイ（Mammalian Methylation Consortium）に関するデータやコード群。
   * `age_cheetah/`: 絶滅危惧種チーターの保全に向けた、DNAメチル化に基づく年齢・性別予測モデル（CheetahClock）に関するデータやコード群。
   * `age_human/`: ディープラーニングを用いた汎組織的なヒトDNAメチル化エピジェネティック・クロック（AltumAge）に関するデータやコード群。

## 基本方針
プロジェクト内の作業ルールやドキュメントの詳細な役割については、`AGENTS.md` を参照してください。基本的に、オリジナルコードの直接の破壊的変更は避け、実験的な試みは個別の環境下で行うことを方針としています。
