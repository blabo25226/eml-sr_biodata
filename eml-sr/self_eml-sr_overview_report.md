# 1. 概要 (eml_sr ライブラリ)
**eml_sr** は、連続数学の根本的な発見の1つである「すべての初等関数は単一の EML 演算子で表現できる」という性質に基づいて構築された、高性能な Rust ライブラリ（Pythonバインディング付き）です。

従来の抽象構文木（AST）は、加算、乗算、三角関数など多種多様なノードを組み合わせるため、最適化や数式の探索が非常に複雑になります。対して eml_sr は、**EML演算子** (`eml(x, y) = e^x - ln(y)`) を数学の「NANDゲート」のような普遍的な構成要素として扱い、あらゆる数式を単一の均質な二分木（Homogeneous Binary Tree）で表現します。

これにより、人工知能によるシンボリック回帰（記号回帰）において、従来行われていた「様々な関数の組み合わせを探索する離散的な組み合わせ最適化」を、「単一の巨大なEML木の重みを勾配降下法（Adamなど）で最適化する連続最適化」へと劇的に変化させます。学習後に重みをスナップ（丸め）することで、AIの予測を解釈可能な数式として抽出でき、AIの「ブラックボックス問題」の解決に寄与します。

（本理論の発見者は Andrzej Odrzywołek 氏であり、関連論文として『All elementary functions from a single operator』が挙げられます。）

# 2. eml-sr フォルダの概要
`eml-sr/` フォルダ内には、eml_sr ライブラリのソースコードやドキュメント、サンプルスクリプトが含まれています。

各主要ファイル・フォルダの内容は以下の通りです：
* `README.md` / `READMEVN.md`: eml_sr の哲学、機能、アーキテクチャの解説、および利用方法が記載されたドキュメント（英語およびベトナム語）。
* `src/`: Rust で書かれた eml_sr のコアエンジンのソースコード。
* `docs/`: 開発者の見解（WHATITHINK.txt）や現状の制約事項（STATUS.md）などをまとめた詳細なドキュメント群。
* `examples/`: eml_sr の活用方法を示す Rust のサンプルコード。
* `example_python.py`: Python（Scikit-Learn 互換 API）から eml_sr を利用してシンボリック回帰を行うための簡単なサンプルスクリプト。
* `Cargo.toml` / `pyproject.toml`: それぞれ Rust および Python のパッケージ管理ファイル。

# 3. 略語・用語一覧
本ドキュメントおよび関連ファイル内で使用されている主な略語・用語の解説です。

* **eml (EML operator)**: Exp-Minus-Log 演算子の略。`eml(x, y) = exp(x) - ln(y)` で定義され、定数1と組み合わせることで四則演算や初等関数を含むあらゆる数式を表現できる強力な二項演算子です。
* **AST (Abstract Syntax Tree)**: 抽象構文木。数式の構造を木構造で表現したもの。従来のAST（Heterogeneous AST）は多様な演算子ノードから構成されます。
* **Homogeneous Binary Tree**: 均質な二分木。eml_sr において、すべてのノードが同一の `EmlNode` で構成される構造を指します。処理の分岐が減るため、コンパイラや最適化が劇的にシンプルになります。
* **Symbolic Regression (記号回帰)**: データセット（入力Xと出力y）から、その関係を最もよく説明する「数式」そのものを探索・発見する機械学習手法。
* **Continuous Optimization (連続最適化)**: 離散的な選択（どの関数を使うか）の代わりに、微分可能な重みパラメータを勾配降下法などで少しずつ更新していく最適化アプローチ。eml_sr によりシンボリック回帰がこの形式に変換可能となります。
