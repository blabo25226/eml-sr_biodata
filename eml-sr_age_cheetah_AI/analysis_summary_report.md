# 分析まとめレポート: EMLを用いたチーターの非線形エピジェネティック年齢予測モデル構築

## 1. 分析の目的と背景
絶滅危惧種であるチーターの健康管理や保全活動において、正確な年齢推定は極めて重要です。従来の手法（CheetahClock）ではElastic Net等の線形モデルを用いてDNAメチル化データから年齢を予測していました。本プロジェクトでは、より高い表現力と解釈性を持つ「EML（Exp-Minus-Log）演算子に基づくシンボリック回帰アルゴリズム」を適用し、非線形な相互作用（活性化・抑制モジュール）を捉えたエピジェネティック年齢予測モデルを構築することを目的としました。

## 2. Elastic Netによる特徴量選択の結果
数万におよぶCpGサイト（超高次元データ）から、年齢予測に強く寄与する重要な特徴量を抽出するため、前処理としてElastic Net（L1/L2正則化）を適用しました。
- 対象データ: `GSE310779` メチル化マトリックス（57サンプル、37,554 CpGサイト）
- 前処理: チーターの性成熟年齢（ASM=2歳）を考慮した対数線形年齢変換（Age_trans）を適用
- 選定結果: 過学習を防ぎつつEMLによる探索空間を現実的にするため、絶対値係数の高い上位50個のCpGサイトを抽出しました。

## 3. EMLモデルの構造と獲得された数式
抽出された50個のCpGサイトを入力としてEMLシンボリック回帰（`max_complexity=10`）を実行し、以下の非線形方程式を獲得しました。

**獲得された数式（Python表記）:**
```python
Age_trans = (np.arccos(cg02909927)) * (cg10820794 / cg02153665 / cg05983884) - cg10501210
```

**LaTeX表記:**
$$ \text{Age}_{trans} = \arccos(\text{cg02909927}) \cdot \frac{\text{cg10820794}}{\text{cg02153665} \cdot \text{cg05983884}} - \text{cg10501210} $$

この数式は、従来の線形加算モデル（$\sum w_i x_i$）とは全く異なり、複数の遺伝子領域が複雑に絡み合うネットワーク的構造を示しています。

## 4. 予測精度の評価とベンチマーク比較
ホールドアウトしたテストデータ（20%）に対する各モデルの予測精度（変換後年齢 `Age_trans` に対する指標）を比較しました。

| モデル | MAE (平均絶対誤差) | R² (決定係数) |
| :--- | :---: | :---: |
| Elastic Net (ベースライン・線形) | 0.8249 | 0.8903 |
| EML Symbolic Regression (非線形) | 1.7544 | 0.5091 |
| Random Forest (非線形・ブラックボックス) | 1.8048 | 0.4431 |

- **考察**: 今回の小サンプル設定においては、過学習に強い線形モデル（Elastic Net）が最も高い汎化性能を示しました。
- しかし、EMLモデルはRandom Forestよりも高い精度（R²=0.5091）を達成しており、なおかつ「完全なホワイトボックス（明示的な数式）」として出力される点に大きな技術的優位性があります。

## 5. 獲得された数式が示す生物学的な考察
獲得された数式は、遺伝子の「活性化（乗算・分子）」と「抑制（除算・分母・減算）」のモジュールとして解釈できます。

1. **加齢を促進・増幅するモジュール（活性化）**:
   - `cg10820794` は分子に位置しており、この部位のメチル化が進行すると予測年齢が増大します。これは加齢に伴い機能が低下する遺伝子群（プロモーターのメチル化による発現抑制）を反映している可能性があります。
2. **加齢を抑制・減速するモジュール（抑制）**:
   - `cg02153665` と `cg05983884` は分母に位置し、これらが高いほど年齢が低く見積もられます。生物学的年齢を若く保つ（あるいは若年期に特有の）エピジェネティックな保護機能として働いていると解釈できます。
   - 同様に `cg10501210` はモデル全体から減算されており、ベースラインの年齢を押し下げる「ブレーキ」の役割を果たしています。
3. **非線形スイッチング（$\arccos$）**:
   - `cg02909927` に対しては逆余弦（$\arccos$）が適用されています。メチル化率（0~1）が1に近づくほど値は急激に0に漸近するため、この部位のメチル化が「ある閾値を超えると加齢シグナル全体をシャットダウン（あるいは急減）させる」ような非線形のスイッチとして機能していることが示唆されます。

以上の結果から、EMLを用いたシンボリック回帰は、単なる予測精度の追求だけでなく、従来の線形解析では見過ごされてきた「遺伝子間の抑制的フィードバック（割り算）」や「非線形スイッチ」といった生物学的ダイナミクスの仮説生成に強力なツールとなることが確認されました。

## 6. 【追記】MEb（動的システム向けEML）の静的タスクへの適応と検証
本分析の追加要件として、「MEb (Manuscript_EML_biophysics)」リポジトリ本来のソースコード（Python上でのAST木探索と連続最適化による常微分方程式ソルバ）を、静的な年齢予測タスクに適応させるための改修を行いました。

### 6-1. アルゴリズムの改修（ハック）内容
元のMEbは「時間 $t$」を入力とし、ベースノード $R(t)$ の非線形ダイナミクスを当てはめる構造です。これを回帰タスクに転用するため、以下の改修を行いました（`MEb_static_regression.py`）。
1. **入力変数の静的化**: $R(t)$ を廃止し、Elastic Netで重要度トップ3となったCpGサイト（`cg10501210`, `cg12544505.2`, `cg23090567`）を直接のベースノード（$V_0, V_1, V_2$）とするよう文法を再定義。
2. **目的関数の変更**: 時系列シミュレーション用のwMSE（重み付き二乗誤差）から、静的データの予測値と実測値の二乗誤差を最小化する純粋な回帰目的関数へ変更。
3. **AST探索の制限**: 組み合わせ爆発を防ぐため、探索空間を `max_depth=3`, `max_nodes=5` に制限。

### 6-2. 実行結果と考察
生成された81通りのAST（数式木）に対して `scipy.optimize.least_squares` でパラメータを最適化した結果、AICが最も低く最適と判定されたのは以下の数式でした。

**Best Model Canonical: `V0` (`cg10501210`)**
- **Test MAE**: 1.8881
- **Test R²**: 0.4747

**考察:**
- Scipyによるパラメータ連続最適化を用いたMEbベースの探索では、EMLゲート（G）による複雑な非線形変換を追加しても、ペナルティ（AICの増加）を上回るほどの精度向上が得られず、結果として最もシンプルな「トップ1のCpGサイトを用いた線形モデル」が最適と判定されました。
- このR²（0.4747）は、単一変数モデルとしては非常に優秀ですが、Rustベースの `eml-sr`（R²=0.5091）や完全な線形モデル（Elastic Net）には及びません。
- これは、MEbのような「Python上でのAST構築＋Scipy最適化」というアプローチが、数十〜数百パラメータの静的回帰タスクにおいては（計算量や局所最適解の問題で）スケールしづらいことを示しており、回帰タスクにおいては高速なビームサーチを備えた `eml-sr` パッケージの方が実用的であることが確認されました。
