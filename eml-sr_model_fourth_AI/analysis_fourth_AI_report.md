## 1. 概要

GEO **GSE310779** に対し、原著 `CheetahClock_age_sex.Rmd` 準拠の **R** 前処理（WGCNA, ComBat, ASM, `glmnet` LOOCV）の上で、以下を実施した。

| Step | 手法 | 入力 |
|:---:|:---|:---|
| 0 | Elastic Net 線形回帰 | 全選択 CpG（42） |
| 1 | EML-SR（`eml-sr_model_first_AI`） | 上位 20 CpG |
| 2 | PySR（遺伝的プログラミング） | 上位 20 CpG |
| 3 | EQL ニューラル SR（PyTorch） | 上位 20 CpG |
| 4 | Sparse Simple Index Model | 上位 20 CpG |

Step 4 では **インデックス $\eta$ の推定**に加え、単変量リンク **$g(\eta)$** を 3 次 B スプライン（5 knots）で特定した。

#### 4.4.2 リンク関数 $g(\eta)$ の特定（3 次 B スプライン、5 knots）

$\eta$ を 1 次元に射影したうえで、**単変量リンク $g$** を `SplineTransformer`（degree $=3$, `n_knots=5`）+ `LinearRegression` で全データ学習した。

**$g$ の定義**

$$
g(\eta) = c_0 + \sum_{k=0}^{5} c_k\, B_k(\eta)
$$

ここで $B_k(\eta)$ は sklearn の B スプライン基底（`include_bias=False`）、$c_0$ は線形回帰の切片である。

**推定された $g$（本 Run の数値）**

$$
\begin{aligned}
g(\eta) =\;& 4.227524
- 1.597977\, B_0(\eta)
- 8.341209\, B_1(\eta) \\
&- 4.056092\, B_2(\eta)
- 2.319326\, B_3(\eta)
+ 0.221109\, B_4(\eta)
+ 3.311358\, B_5(\eta)
\end{aligned}
$$

| パラメータ | 記号 | 値 |
|:---|:---|---:|
| 切片 | $c_0$ | 4.227524 |
| $B_0(\eta)$ の係数 | $c_0^{(B)}$ | $-1.597977$ |
| $B_1(\eta)$ の係数 | $c_1$ | $-8.341209$ |
| $B_2(\eta)$ の係数 | $c_2$ | $-4.056092$ |
| $B_3(\eta)$ の係数 | $c_3$ | $-2.319326$ |
| $B_4(\eta)$ の係数 | $c_4$ | $+0.221109$ |
| $B_5(\eta)$ の係数 | $c_5$ | $+3.311358$ |

$\eta$ の学習データ範囲: $[-2.551,\, 6.738]$。係数の生データは `results/step4_sim_g_coefficients.csv`。

\eta = 2.262514 + \sum_{j=1}^{20} \beta_j^{\mathrm{enet}} \tilde{x}_j

**Step 3**: リンク $g$ で `age_trans` を予測する。

$$
\widehat{\text{age\_trans}} = g(\eta) = c_0 + \sum_{k=0}^{5} c_k\, B_k(\eta)
$$

以上をまとめると、本 Run の Sparse SIM は

$$
\boxed{
\widehat{\text{age\_trans}}
= g\!\left(
\beta_0^{\mathrm{enet}} + \sum_{j=1}^{20} \beta_j^{\mathrm{enet}}
\frac{\mathrm{CpG}_j - \mu_j}{\sigma_j}
\right)
}
$$

であり、**$g$ はスプライン係数 $c_0,\ldots,c_5$ として上表のとおり特定された**。

**LOOCV**: MSE $=0.35$, $R^2=0.960$, $r_{\mathrm{age}}=0.976$, MAE $=0.86$ 年。

## 5. 考察

1. **Step 4** は $\eta=\beta^\top x$ と **$g(\eta)$ のスプライン**を分離して推定した。数値上は最良だが、$n=48$ に対するスプライン自由度は過大になりうる。
2. **PySR（Step 2）** は LOOCV $r\approx 0.94$ と Elastic Net を上回り、$\log$・$\sin$ を含む解釈可能な式を得た。EML-SR より高次だが候補 10 件を列挙できた。
3. **EML-SR** は低複雑度の有理式（Rank 1: 3 CpG の比）を発見するが、LOOCV では EN・PySR に劣る。
4. **EQL** は本 Run では LOOCV が負に近く、実用には不向き。
5. **Elastic Net** は 42 項の線形式として安定したベースライン（$r\approx 0.76$）。
